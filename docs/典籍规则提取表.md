# 典籍规则提取表

> 本文是「命理规则引擎」的前置成果：把中国传统命理文献中**可判定的「条件 → 结论」**抽取为结构化条目，再由 `src/rules/*.json` 交给引擎执行。
>
> **性质**：文化研究与娱乐用途。所有条目均标注所出典籍，但不是古籍原文校勘，而是对公开资料中记载的通行主张的结构化改写。命理不具备科学预测效力。

---

## 一、方法与边界

### 1.1 提取标准

只有满足以下三条的表述才被收进规则库：

1. **要素可判定**：条件必须落在天干、地支、十神、五行、神煞、卦爻、日期等可计算对象上。像「以中和为贵」「须通变」这类无法判定真假的判断，只作为注释，不进规则库。
2. **结论可归因**：每条结论必须能指回具体书名与篇目，不允许「综合各家」式的无主结论。
3. **正负可赋分**：能判断倾向为吉、凶或中性，否则分值置 0（例如「神煞宜作参看」这类判读原则）。

### 1.2 置信度分级

| 级别 | 含义 |
|---|---|
| A | 该主张在多部典籍或多个独立公开资料中一致出现，可查证 |
| B | 仅见于单一整理资料，或属于该流派独有之说，需二次核验 |
| C | 后世归纳的结构共性，古籍未见如此直接表述 |

### 1.3 未做的事

- **没有**逐字校对古籍善本。文中引用的书名、作者、年代以通行说法为准，个别托名之书的真实成书年代学界仍有争议。
- **没有**把互相矛盾的流派强行统一。例如《增删卜易》主张「用克世作吉看」，《卜筮正宗》持相反立场，两者都保留并各自标注出处。
- **没有**收录需要现场外应、师承口诀、面相等无法从生辰数据推出的内容。

### 3.10 流日运势（33 条，跨 6 部）

## 四、跨典籍共识规则

以下 8 条在至少三部典籍中反复出现，是整个体系的公共地基，已直接写入 `tables.py` 与 `calendar_core.py`，不再单独计为某本书的规则。

1. **五行生克**：木生火、火生土、土生金、金生水、水生木；木克土、土克水、水克火、火克金、金克木。（《渊海子平》《三命通会》《滴天髓》均以此为底层）
2. **十神定义**：以日干为我，同我比肩劫财、我生食神伤官、我克偏财正财、克我七杀正官、生我偏印正印。（《渊海子平》确立，《子平真诠》细化）
3. **以日干为主**：宋以后子平法以日柱天干为命主，取代古法以年柱为本。（《渊海子平》开其端）
4. **月令为提纲**：格局以月支本气所透十神而定。（《子平真诠》「八字用神，专求月令」）
5. **日主强弱判断**：得令、得地、得生、得助四因素综合。（《滴天髓》衰旺篇）
6. **财官印食为四吉神，杀伤枭刃为四凶神**，但凶神有制反成权。（《渊海子平》《三命通会》）
7. **神煞为辅，格局为主**：神煞与格局冲突时以格局为准。（《五行精纪》及诸家）
8. **调候为急**：寒暖燥湿失衡时，先调候再论扶抑格局。（《穷通宝鉴》《滴天髓》）

## 五、规则化中的取舍与已知局限

1. **量化是人为的**。典籍只说「吉」「凶」，不说几分。分值（+1 至 +4）是本项目为了排序与汇总而赋的权重，不是古籍原有内容。改动权重会改变综合结论，这是方法本身的软肋，故在界面上同时展示「命中条数」与「均分」，避免单一数字造成伪精确。
2. **强弱判断是估算**。五行力量用「天干各 1.0、月干 1.2、藏干按 0.6/0.3/0.1 加权」的简化模型，不同命理师的手工判断会有出入。
3. **节气精度约 ±15 分钟**。太阳黄经用 Meeus 低精度公式，交节前后一刻钟内出生者，月柱可能排错。生产级应用应换高精度星历。
4. **神煞取法有流派分歧**。羊刃有「阳干专论」与「十干皆论」两派；天乙贵人有「甲戊庚牛羊」与「甲戊并牛羊」的差异。本项目取通行口径并在 `tables.py` 注明。
5. **晚子时处理**。23:00–23:59 出生按次日日柱计算（晚子时法）。另有「日柱不换、时柱换」的早子时法，本项目未采用。
6. **紫微未排盘**（见 3.4）。
7. **没有收录**：风水形法、面相手相、奇门遁甲、大六壬、择日中的具体事项宜忌（仅到建除层面）、以及一切需要外应和师承口诀的内容。
