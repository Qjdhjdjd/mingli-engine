命理规则引擎29 部典籍 · 152 条可执行规则

把《渊海子平》《三命通会》《滴天髓》这类古籍里可判定的条款抽出来， 写成「条件 → 结论」的结构化规则，再由程序逐条匹配、逐条溯源。 它复现的是古人的推理方式，不是对现实的预测。

示例完整排盘报告→
一份预先算好的八字报告：四柱排盘、十神藏干、神煞、五行强弱、命中的每条规则及其出处。
核心典籍规则提取表→
29 部典籍逐条列出：书名、年代、体系、规则条件、吉凶分值、置信度。附跨典籍共识规则。
说明大模型解读层怎么做的→
模型只负责把规则结果讲成人话，吉凶仍由引擎产生；生成后由程序校验编号、分值与绝对化措辞。
源码项目仓库→
零依赖 Python 实现：节气天文推算、规则引擎、五套分析器、本地 Web 界面与命令行。
关于这份东西能做什么。 排盘精度可以做到分钟级、每条结论可以回指到具体书名，这些是可核对的。 但「由此可以推断人生」这一步，是文献的断言，不是程序的推导。 请当作文化研究与娱乐，不要用它决定就医、签约、投资这类真事。 交互式界面需要本地运行 Python 后端，本页只提供静态示例。
